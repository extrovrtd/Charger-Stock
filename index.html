This uses a free Google Firebase project as the shared database. Do this once to create it, then enter the same values on every phone.

  1. Go to console.firebase.google.com and sign in with a Google account.
  2. Click Add project, give it any name (e.g. "charger-stock"), and finish creating it.
  3. In the project, click the </> (web) icon to register a web app. Skip hosting.
  4. Firebase shows a code block called firebaseConfig — copy each value into the matching field below.
  5. In the left menu, go to Build → Firestore Database → Create database, and start in test mode (choose the region closest to you).
  6. Open the Rules tab of Firestore and replace the contents with the rules shown below, then click Publish (test mode rules expire after 30 days otherwise).
These values let any device read and write this one inventory document — nobody else will have them unless you share them, but don't post them anywhere public (like a public GitHub repo).
rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /chargerTrackerApp/{doc} { allow read, write: if true; } } }
